## ⭐ Featured project

<a href="https://github.com/Salmankbdev/file-organizer-pro">
  <img src="https://raw.githubusercontent.com/Salmankbdev/Salmankbdev/main/assets/featured-file-organizer.svg" alt="File Organizer Pro — scan, organize, undo" width="100%" />
</a>

**File Organizer Pro** turns a messy Windows folder into a tidy one — with a full preview before anything moves, and one-click undo after.

- 👀 **Preview, then apply** — every move is shown first, and conflicts get `name (1).ext` instead of overwriting
- ↩️ **Undo anything** — the full operation history survives restarts
- 🔍 **Understand your files** — SHA-256 duplicate finder, large-file finder, storage analytics, custom rules
- 🧹 **Do more in one place** — batch rename, archive extraction, cache cleanup
- 🛡️ **Private by design** — 100% offline, local SQLite storage, no account, no telemetry
- 🧪 **Tested and shipped** — Flutter + Dart, v1.7.0, MIT licensed, released through GitHub Actions
